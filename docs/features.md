# Pathloom — Feature catalog (Stage 2, чернетка)

Статус: на погодженні у власника. Рішення D1–D17 — у [discovery.md](discovery.md).

> Оновлення: після D18 одиниця плану — **картка етапу** зі списком задач, а не окрема Task card. Де цей файл розходиться з [spec.md](spec.md), правильна специфікація.

Принцип відбору MVP: один повний сценарій «відкрив папку → намалював/AI згенерував план → бачу, що робити далі → відмічаю прогрес → git commit». Все, що не служить цьому сценарію, — пізніше.

## MVP

### Полотно
- Інструменти: select, hand, rectangle, ellipse, diamond, line, arrow, pencil, text, image, sticky note, frame, eraser. Цифрові shortcuts.
- Pan/zoom (тачпад, колесо, `Space`+drag), zoom-to-fit, zoom-to-selection.
- Multi-select, copy/paste, duplicate, undo/redo, z-order, lock, resize, rotate.
- Стрілки прив'язуються до фігур і карток (binding) і переїжджають разом з ними.
- Властивості: колір обведення/заливки, товщина, стиль лінії (суцільна/пунктир), прозорість, наконечники, розмір шрифту.
- Snap to grid, базове вирівнювання (align left/center/…).
- Стиль рендеру clean / sketch; mixed за замовчуванням.
- Фон: dots / grid / порожній. Мінімапа.
- **Semantic zoom**: на малому масштабі картки показують лише назву, статус і прогрес. Потрібно і для читабельності, і для швидкодії.

### Проєкт і навігація
- Стартовий екран: недавні папки, «Open folder», «New project».
- Дерево файлів зліва: папки й дошки (папки = звичайні папки на диску).
- Створити / перейменувати / дублювати / видалити дошку.
- Вкладки відкритих дошок, back/forward, breadcrumbs.
- Quick open (`Ctrl+P`), command palette (`Ctrl+K`), глобальний пошук (`Ctrl+Shift+F`) по задачах і дошках.

### Smart objects
- **Task card**: назва, опис (Markdown), статус, пріоритет, дедлайн, теги, чекліст (1 рівень вкладення), прогрес, коментарі (автор human/agent), вкладені зображення, поля `branch` / `pr`.
- **Milestone**: ромб-«ворота»; прогрес = прогрес задач, які в нього входять; дата необов'язкова.
- **Board portal**: картка-посилання на іншу дошку; подвійний клік відкриває її, показує прогрес цієї дошки.
- **Note / sticky**: вільний текст.
- `Convert to task` для фігури (зберігає позицію й колір) і `Detach` назад. `Promote` пункту чекліста до окремої задачі.
- Одна задача може мати картки на кількох дошках.

### Roadmap-логіка
- Залежність = стрілка між задачами/milestone (окремий тип ребра, візуально відрізняється від звичайної стрілки).
- Заборона циклів (стрілку, що створює цикл, не можна поставити; пояснення в тості).
- Обчислювані стани: **ready** (усі залежності виконані), **blocked** (є невиконана залежність). Blocked — не статус, а наслідок графа.
- Фаза = frame; заголовок frame показує прогрес задач у ньому.
- Execution mode: ховає виконане, підсвічує ready, приглушує решту, дозволяє лише змінювати статуси.
- Auto-layout вибраного (layered, зліва направо).

### Перегляди
- Board (полотно).
- Task list: таблиця всіх задач проєкту з фільтрами (статус, пріоритет, тег, ready/blocked) і сортуванням.

### AI та агенти
- `pathloom` CLI: `init`, `board create`, `task add/update/done`, `link`, `next`, `query`, `apply <spec>`, `validate`.
- `pathloom mcp` (stdio): ті самі операції; read-запити з фільтрами й пагінацією; batch-операції в одній транзакції; структуровані помилки.
- Декларативний spec для дошки (вузли, типи, зв'язки, підказки layout) → Pathloom сам розкладає.
- Skill/плагін для Claude Code: формат файлів, команди, приклади.
- Live reload: застосунок стежить за `plan/` і миттєво показує зміни; зроблене агентом підсвічується; уся сесія агента — один undo.

### Збереження
- Файли — джерело правди (D3). Атомарний запис, автозбереження.
- Індекс SQLite у `.pathloom/cache/` для пошуку; перебудовується з файлів.
- Конфлікт «агент змінив те, що я редагую» → показати, не перезаписувати мовчки.

### Оформлення й дистрибуція
- Дві теми: Midnight (темна) і Light. Теми = JSON-токени; можна покласти свою в `.pathloom/themes/`.
- i18n: English, Українська.
- Інсталятори: під час розробки збираємо локально (Windows напряму, Linux через WSL). GitHub Actions (у т.ч. macOS) — наприкінці MVP; для публічного репо хвилини безкоштовні. Без підпису на старті.

## V1

- Kanban view (той самий набір задач, колонки = статуси).
- Proposal mode: зміни агента як ghost-overlay → прийняти / відхилити.
- Timeline view (задачі з датами на осі часу).
- Export PNG / SVG, експорт дошки в Markdown-звіт.
- Presentation mode (frames як слайди), laser pointer, highlighter.
- Document card (довгий Markdown з таблицями й кодом), code snippet card, link card з превʼю.
- Backlinks: «де ця задача/дошка згадується».
- Збережені фільтри, critical path, згортання фаз.
- Git-статус у задачі: існує гілка, злитий PR, останній коміт (з локального git, без GitHub API).
- Smart guides, distribute, більше тем, шаблони дошок.
- Авто-оновлення, підпис інсталяторів.

## V2

- Плагіни: власні smart-об'єкти й команди.
- Власні статуси й поля задач.
- Calendar view, decision node.
- Git merge driver для `*.board.json`.
- MCP по localhost HTTP; dashboard кількох агентів.
- Інтеграція з GitHub Issues/PR, імпорт з Jira/Trello.
- Snapshots/історія дошки в UI.

## Пізніше / експерименти

- Опційний хмарний синк, real-time колаборація.
- Вбудований AI-чат.
- Marketplace тем і шаблонів.
- Мобільний переглядач.

## Свідомо вирізано з MVP

- Recurring tasks, estimates, time tracking — не для цієї аудиторії на старті.
- Activity history — її дає `git log`.
- Вкладені sub-boards окремою сутністю — їх замінюють portals.
- Окремі «двигуни» для Kanban/Mind map — це перегляди й шаблони над однією моделлю.

## Залежності між фічами

- Формат файлів і `pathloom-core` → усе інше.
- Binding стрілок → залежності → ready/blocked → `next`, Execution mode, MCP.
- File watcher → live reload агентських змін → proposal mode (V1).
- Task list → Kanban (V1) → Timeline (V1).

## Перший робочий milestone (M1)

Запустити застосунок → створити проєкт → відкрити дошку → намалювати фігури → додати task cards → з'єднати їх → зберегти й відкрити знову.
